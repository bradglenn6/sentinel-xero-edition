# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a Vulnerability

ZeroLabz takes post-quantum and zero-trust security seriously. Please do not open public issues for suspected vulnerabilities.

Report security vulnerabilities privately via GitHub Private Vulnerability Reporting or email **dev@zrolabz.com** with reproduction steps and affected components. You will receive an acknowledgment within 48 hours.
